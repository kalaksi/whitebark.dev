Lightkeeper helps you maintain Linux hosts over SSH.

Lightkeeper

Lightkeeper brings host status, logs, files, and terminals together, reducing repetitive shell work. It connects over SSH and uses standard Linux commands, so nothing needs to be installed on your servers. Its debug log shows the commands it runs.

  • Alerts when a host's status changes.
  • Remote file browsing and editing.
  • Hotkeys throughout, so you can work without digging through menus.

Install

  1. Install from Flathub. Sandboxed, with the minimum permissions required.
  2. Download a Debian or Fedora package from GitHub Releases.
  3. Build from source.
